# DoorWatch 🔔

**Interphone intelligent pour Home Assistant**

> *Votre porte. Vos données. Aucun cloud.*

DoorWatch connecte votre sonnette à votre téléphone via Home Assistant.
Notification instantanée, flux vidéo en direct, reconnaissance faciale locale,
et ouverture de la porte — sans abonnement, sans cloud fabricant.

---

## Fonctionnalités

- 🔔 **Notification push** dès que quelqu'un sonne
- 📷 **Flux vidéo** de n'importe quelle caméra Home Assistant
- 🚪 **Ouvrir la porte** depuis l'appli (serrure ou interrupteur HA)
- 📋 **Historique** des visites
- 👤 **Reconnaissance faciale locale** (Pro) — *"Juliette est à la porte"*
- 🔊 **Interphone bidirectionnel** audio WebRTC (Pro)
- 🏠 Compatible **toutes caméras HA** : Ring, Reolink, Frigate, Hikvision…
- 🔒 **100% local** — vos données ne quittent pas votre réseau

## Compatibilité

- Home Assistant 2024.1+
- Navigateur web (Chrome recommandé)
- Accès local, Nabu Casa, ou tunnel Cloudflare

## Installation

1. Cloner le dépôt et lancer `flutter run -d chrome`
2. Ouvrir l'appli et entrer l'URL de votre HA + un token longue durée
3. Choisir votre entité sonnette (binary_sensor) et caméra
4. C'est tout !
